# Keerthana V Portfolio

A lightweight personal portfolio website built with HTML, CSS, and JavaScript. It includes a loading screen, intro reveal animation, sticky navigation, section-based scrolling, and mobile responsive behavior.

## Files

- `index.html` – structure and content
- `css/style.css` – site styling and responsive layout
- `js/script.js` – GSAP animations and navigation interactions
- `assets/images/favicon.svg` – placeholder favicon

## Local preview

Open `index.html` directly in a browser, or run a simple local server from the project folder:

```bash
cd portfolio
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deployment

This project is suitable for deployment on GitHub Pages or Vercel as a static website.
